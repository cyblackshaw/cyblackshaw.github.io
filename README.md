# cyblackshaw.github.io

Personal research website for Christine Ye Shu Blackshaw.

## Publish on GitHub Pages

1. Create a public repository named `cyblackshaw.github.io` on GitHub.
2. Upload the contents of this folder to the repository root.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages** and confirm the site is being served from the `main` branch/root if needed.
5. Visit `https://cyblackshaw.github.io`.
